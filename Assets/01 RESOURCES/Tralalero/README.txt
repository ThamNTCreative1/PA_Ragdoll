TRALALERO TRALALA - ORIGINAL MODEL WITH IDLE

Uses the supplied original ZIP model, preserving its mesh, UVs, pixel texture
and rest pose. Only a stationary Idle rig/clip has been added.
The export is uniformly scaled and oriented for Unity (Y up, +Z forward).
The source archive's 19.949-degree presentation tilt has been removed using
the sole-plane normals. All three soles are level at ground height zero.
The same correction is baked into the mesh and skeleton bind pose.

Tralalero_Idle.fbx: original model, Generic skeleton and Idle animation.
Tralalero_Idle.glb: original model, embedded original texture, rig and Idle.
Tralalero_Original_Idle.prefab: ready to place in Unity, with an Animator
playing the looping Idle clip and the original textured material assigned.
Tralalero_Idle.controller: single Idle state, Apply Root Motion disabled.
Tralalero_Original.mat: original PNG texture, point filtering.
Textures/Tralalero_BaseColor.png: unchanged original PNG.
672 triangles; one skinned mesh; one material; seven bones; one texture.
Idle is four seconds at 24 fps with no root motion.
The body lowers 0.08 metres and returns upright every two seconds;
the four-second clip contains two identical dip/stand cycles.
The three shoes retain their corrected rest positions throughout the animation.
